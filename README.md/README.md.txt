# Superstore Sales Analytics

## 📌 Project Overview

This project analyzes the Superstore Sales dataset to understand sales, profit, customers, products, and overall business performance.

The project uses Python and Power BI to perform data analysis and create an interactive dashboard.

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Power BI
* Matplotlib
* Seaborn
* Jupyter Notebook

## 📊 Key Analysis

* Total Sales
* Total Orders
* Total Profit
* Profit Margin
* Sales by Month
* Sales by Category
* Sales by Sub-Category
* Top Products
* Sales by Region
* Customer Analysis
* Average Order Value
* Profit Analysis

## 🔍 Project Objective

The main objective of this project is to analyze sales data and identify useful business insights such as high-performing products, profitable categories, customer behavior, and regional sales performance.

## 📈 Dashboard

An interactive Power BI dashboard was created to visualize important business KPIs and trends.

## 💡 Key Insights

The analysis helps identify:

* Which products generate the most sales
* Which categories are more profitable
* Monthly sales trends
* Regional performance
* Customer purchasing patterns
* Areas where profit can be improved
